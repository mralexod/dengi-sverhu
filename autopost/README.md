# Автопостинг в t.me/dengisverhu

- `posts.json` — очередь постов (номер, дата, текст). Тексты пишет Claude в базе (`посты-6-35.md`), сюда — копия.
- `send.py` — публикует один пост в день: самый ранний неотправленный, чья дата наступила.
- `sent.txt` — номера уже отправленных постов (дописывает робот).
- `.github/workflows/tg-autopost.yml` — запуск каждый день в 09:30 МСК.

Чтобы заработало: бот добавлен админом канала с правом «Публикация сообщений», его токен лежит в секрете репозитория `TG_BOT_TOKEN`.
Пока токена нет, робот ничего не отправляет, а только печатает в журнал запуска, что ушло бы.

Поставить на паузу: Actions → «Автопостинг в канал» → Disable workflow.
